# Engineering Focus

I'm a Computer Engineering student focused on **Systems Software Engineering and Low-Level Software Development**.

I'm interested in understanding how computers operate beneath application-level abstractions, from processor architecture and memory management to operating systems, concurrency and system-level programming.

My primary technical interests include C/C++, Linux, operating systems, memory management and systems programming. I'm also developing a strong foundation in computer networking, with an interest in understanding how operating systems and network infrastructure interact.

Alongside systems programming, I have experience exploring backend infrastructure, distributed systems concepts and embedded hardware development.

# Engineering Philosophy

> **Understand the machine. Understand the software. Understand the systems connecting them.**

I believe strong engineering comes from understanding the fundamentals beneath abstractions.

Rather than focusing exclusively on frameworks and tools, I enjoy exploring how processors execute instructions, how operating systems manage resources, how memory works and how computers communicate across networks.

My goal is to develop a deep understanding of computer systems and build reliable, efficient software.
